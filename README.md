# Impact Festival

Website for Impact Festival, built with Astro and deployed on Netlify.

## Development

```sh
npm install
npm run dev
```

The local development server is available at `http://localhost:4321`.

## Production build

```sh
npm run build
```

The generated static website is written to `dist/`.

## Deployment

Pushes to the `main` branch are deployed automatically to:

<https://impact-festival.netlify.app>
